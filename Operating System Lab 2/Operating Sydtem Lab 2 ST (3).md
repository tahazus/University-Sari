## ۱. اهداف جلسه

در پایان این جلسه، دانشجو باید بتواند:

۱. با ترمینال لینوکس کار کند و دستورات پایه را اجرا کند.  
۲. مسیر جاری و ساختار پوشه‌ها را بررسی کند.  
۳. فایل‌ها و پوشه‌ها را ایجاد، کپی، جابه‌جا و حذف کند.  
۴. محتوای فایل‌های متنی را مشاهده کند.  
۵. با استفاده از دستورات جست‌وجو، فایل‌ها و عبارت‌ها را پیدا کند.  
۶. راهنمای دستورات لینوکس را مطالعه کند.  
۷. از مسیرهای مطلق و نسبی به‌درستی استفاده کند.

**ارتباط با LPIC-1:** این مباحث عمدتاً با اهداف خط فرمان، مدیریت فایل‌ها و پوشه‌ها و دریافت راهنمای سیستم در آزمون‌های LPIC-1 مرتبط‌اند. شماره دقیق اهداف آزمون ممکن است با نسخه آزمون تغییر کند.

## ۲. آشنایی با ترمینال لینوکس

### سؤال ۱: ترمینال لینوکس چیست؟

**پاسخ:**

ترمینال محیطی است که کاربر می‌تواند از طریق آن دستورات متنی را وارد کند و نتیجه اجرای آن‌ها را مشاهده کند.

در محیط گرافیکی لینوکس، معمولاً برنامه‌ای با نام Terminal وجود دارد. در سرورهای لینوکس نیز ممکن است بیشتر فعالیت‌ها از طریق خط فرمان انجام شوند.

### سؤال ۲: Shell چیست و چه تفاوتی با ترمینال دارد؟

**پاسخ:**

Shell برنامه‌ای است که دستورات واردشده توسط کاربر را تفسیر و اجرا می‌کند یا اجرای آن‌ها را به برنامه‌های دیگر واگذار می‌کند.

ترمینال محیطی برای ورود و مشاهده متن فراهم می‌کند؛ Shell مفسر دستورات است.

یکی از Shellهای رایج لینوکس، Bash است.

### سؤال ۳: ساختار یک دستور لینوکس چگونه است؟

**پاسخ:**

یک دستور معمولاً از نام برنامه، گزینه‌ها و آرگومان‌ها تشکیل می‌شود.

```bash
ls -l /home
```

در این مثال:

- `ls`: نام دستور
- `-l`: گزینه نمایش اطلاعات با جزئیات
- `/home`: مسیر مورد بررسی

گزینه‌ها و آرگومان‌های هر دستور ممکن است متفاوت باشند.

### سؤال ۴: چگونه یک دستور را اجرا کنیم؟

**پاسخ:**

۱. ترمینال را باز کنید.  
۲. دستور موردنظر را وارد کنید.  
۳. کلید Enter را فشار دهید.  
۴. خروجی یا پیام خطا را بررسی کنید.

مثال:

```bash
whoami
```

این دستور نام کاربر فعلی را نمایش می‌دهد.

## ۳. شناخت مسیرها و پوشه‌ها

### سؤال ۵: دستور `pwd` چه کاربردی دارد؟

**پاسخ:**

دستور `pwd` مخفف Print Working Directory است و مسیر کامل پوشه کاری فعلی را نمایش می‌دهد.

```bash
pwd
```

خروجی نمونه:

```text
/home/student
```

این خروجی نشان می‌دهد که کاربر در مسیر `/home/student` قرار دارد.

### سؤال ۶: دستور `ls` چیست؟

**پاسخ:**

دستور `ls` برای نمایش فایل‌ها و پوشه‌های موجود در یک مسیر استفاده می‌شود.

مثال‌ها:

```bash
ls
ls /home
ls -l
ls -a
ls -lh
```

| دستور | کاربرد |
|---|---|
| `ls` | نمایش محتویات مسیر جاری |
| `ls /home` | نمایش محتویات مسیر مشخص |
| `ls -l` | نمایش جزئیات فایل‌ها |
| `ls -a` | نمایش فایل‌های مخفی نیز |
| `ls -lh` | نمایش جزئیات با اندازه‌های خواناتر |

در خروجی `ls -l` معمولاً نوع فایل، مجوزها، تعداد پیوندهای سخت، مالک، گروه، اندازه، زمان تغییر و نام فایل نمایش داده می‌شود.

فایل‌هایی که نام آن‌ها با نقطه آغاز می‌شود، مانند `.bashrc`، در خروجی عادی `ls` نمایش داده نمی‌شوند؛ گزینه `-a` آن‌ها را نیز نشان می‌دهد.

### سؤال ۷: دستور `cd` چه کاربردی دارد؟

**پاسخ:**

دستور `cd` مخفف Change Directory است و برای تغییر پوشه کاری فعلی استفاده می‌شود.

مثال‌ها:

```bash
cd /home
cd ..
cd .
cd ~
cd -
```

توضیح:

- `cd /home`: ورود به مسیر `/home`
- `cd ..`: رفتن به پوشه والد
- `cd .`: باقی‌ماندن در پوشه جاری
- `cd ~`: رفتن به پوشه خانگی کاربر
- `cd -`: بازگشت به پوشه کاری قبلی

### سؤال ۸: تفاوت مسیر مطلق و مسیر نسبی چیست؟

**پاسخ:**

**مسیر مطلق (Absolute Path):** از ریشه فایل‌سیستم، یعنی `/`، شروع می‌شود.

مثال:

```bash
/home/student/docs
```

**مسیر نسبی (Relative Path):** نسبت به پوشه کاری فعلی تفسیر می‌شود.

مثال:

```bash
docs
../downloads
```

فرض کنید مسیر جاری `/home/student` باشد. در این صورت مسیر نسبی `docs` به `/home/student/docs` اشاره می‌کند.

### تمرین کوتاه

دستورات زیر را اجرا کنید و نتیجه را یادداشت کنید:

```bash
pwd
ls
cd /tmp
pwd
cd ~
pwd
```

## ۴. ایجاد فایل و پوشه

### سؤال ۹: دستور `mkdir` چیست؟

**پاسخ:**

دستور `mkdir` مخفف Make Directory است و برای ایجاد پوشه استفاده می‌شود.

مثال:

```bash
mkdir lab
```

این دستور پوشه‌ای با نام `lab` در مسیر جاری ایجاد می‌کند.

برای ایجاد چند پوشه:

```bash
mkdir docs images backups
```

برای ایجاد ساختار چندسطحی، از گزینه `-p` استفاده می‌کنیم:

```bash
mkdir -p university/os2/session3
```

اگر پوشه‌های میانی وجود نداشته باشند، با استفاده از `-p` ایجاد می‌شوند.

### سؤال ۱۰: دستور `touch` چه کاربردی دارد؟

**پاسخ:**

دستور `touch` برای ایجاد فایل خالی در صورتی که فایل وجود نداشته باشد، یا به‌روزرسانی زمان‌های دسترسی و تغییر فایل موجود استفاده می‌شود.

مثال:

```bash
touch notes.txt
touch test1.txt test2.txt
```

**نکته:** اجرای `touch` روی فایل موجود معمولاً محتوای آن را پاک نمی‌کند؛ بلکه زمان‌های مربوط به فایل را به‌روزرسانی می‌کند.

### سؤال ۱۱: چگونه چند پوشه و فایل برای تمرین ایجاد کنیم؟

**پاسخ:**

دستورات زیر را به‌ترتیب اجرا کنید:

```bash
mkdir -p ~/os2-lab/session3/docs
mkdir -p ~/os2-lab/session3/backup
touch ~/os2-lab/session3/docs/notes.txt
touch ~/os2-lab/session3/docs/questions.txt
ls -l ~/os2-lab/session3/docs
```

در این تمرین، یک پوشه آزمایشگاهی همراه با دو پوشه داخلی و دو فایل ایجاد می‌شود.

## ۵. کپی، انتقال و حذف فایل‌ها

### سؤال ۱۲: دستور `cp` چیست؟

**پاسخ:**

دستور `cp` برای کپی‌کردن فایل‌ها و پوشه‌ها استفاده می‌شود.

ساختار کلی:

```bash
cp source destination
```

مثال:

```bash
cp notes.txt notes-copy.txt
```

این دستور یک کپی از فایل `notes.txt` با نام `notes-copy.txt` ایجاد می‌کند.

کپی فایل به پوشه دیگر:

```bash
cp notes.txt backup/
```

کپی پوشه همراه با محتویات آن:

```bash
cp -r docs docs-copy
```

گزینه `-r` برای کپی بازگشتی پوشه‌ها و محتویات آن‌ها استفاده می‌شود.

### سؤال ۱۳: دستور `mv` چه کاربردی دارد؟

**پاسخ:**

دستور `mv` برای انتقال فایل‌ها و پوشه‌ها یا تغییر نام آن‌ها استفاده می‌شود.

تغییر نام فایل:

```bash
mv notes.txt lesson-notes.txt
```

انتقال فایل به پوشه دیگر:

```bash
mv lesson-notes.txt backup/
```

انتقال پوشه:

```bash
mv docs backup/
```

### سؤال ۱۴: دستور `rm` چیست؟

**پاسخ:**

دستور `rm` برای حذف فایل‌ها استفاده می‌شود.

مثال:

```bash
rm old.txt
```

حذف چند فایل:

```bash
rm file1.txt file2.txt
```

حذف پوشه همراه با محتویات آن:

```bash
rm -r old-folder
```

گزینه `-i` پیش از حذف هر مورد، درخواست تأیید می‌کند:

```bash
rm -i old.txt
```

**هشدار آزمایشگاهی:** دستور `rm` معمولاً فایل‌ها را به سطل زباله گرافیکی منتقل نمی‌کند. حذف با این دستور ممکن است به‌آسانی قابل بازگردانی نباشد. در تمرین‌های دانشجویی فقط از فایل‌ها و پوشه‌هایی استفاده کنید که خودتان ساخته‌اید.

### سؤال ۱۵: دستور `rmdir` چه تفاوتی با `rm -r` دارد؟

**پاسخ:**

دستور `rmdir` فقط پوشه‌های خالی را حذف می‌کند.

```bash
mkdir empty-dir
rmdir empty-dir
```

اما `rm -r` می‌تواند پوشه و محتویات آن را حذف کند.

بنابراین، برای حذف پوشه‌ای که باید خالی باشد، `rmdir` انتخاب محدودتر و مطمئن‌تری است.

### تمرین عملی

```bash
cd ~/os2-lab/session3
touch file1.txt
cp file1.txt file2.txt
mv file2.txt renamed.txt
mkdir testdir
mv renamed.txt testdir/
ls -l testdir
```

در پایان، فایل‌ها و پوشه‌های ایجادشده را بررسی کنید.

## ۶. مشاهده محتوای فایل‌ها

### سؤال ۱۶: دستور `cat` چیست؟

**پاسخ:**

دستور `cat` برای نمایش محتوای فایل و همچنین ترکیب محتوای چند فایل در خروجی استفاده می‌شود.

```bash
cat notes.txt
```

برای نمایش محتوای چند فایل پشت سر هم:

```bash
cat file1.txt file2.txt
```

برای ایجاد فایل متنی ساده با ورودی ترمینال:

```bash
cat > sample.txt
```

پس از واردکردن متن، با فشردن `Ctrl+D` ورودی پایان می‌یابد.

**نکته:** اگر فایل موجود باشد، استفاده از `>` محتوای قبلی آن را جایگزین می‌کند. با احتیاط از این روش استفاده کنید.

### سؤال ۱۷: دستور `less` چه کاربردی دارد؟

**پاسخ:**

دستور `less` برای مشاهده صفحه‌به‌صفحه فایل‌های متنی، به‌خصوص فایل‌های طولانی، استفاده می‌شود.

```bash
less /var/log/syslog
```

در برخی توزیع‌ها ممکن است نام یا محل فایل گزارش متفاوت باشد.

کلیدهای پرکاربرد در `less`:

- `Space`: رفتن به صفحه بعد
- `b`: رفتن به صفحه قبل
- `/text`: جست‌وجوی عبارت
- `n`: رفتن به نتیجه بعدی جست‌وجو
- `q`: خروج

### سؤال ۱۸: تفاوت `head` و `tail` چیست؟

**پاسخ:**

`head` خطوط ابتدایی فایل و `tail` خطوط انتهایی آن را نمایش می‌دهد.

```bash
head notes.txt
tail notes.txt
```

نمایش پنج خط اول:

```bash
head -n 5 notes.txt
```

نمایش ده خط آخر:

```bash
tail -n 10 notes.txt
```

نمایش پیوسته خطوط جدید یک فایل گزارش:

```bash
tail -f application.log
```

گزینه `-f` برای مشاهده تغییرات جدید فایل، مانند اضافه‌شدن خطوط گزارش، کاربرد دارد.

## ۷. جست‌وجوی فایل‌ها و متن

### سؤال ۱۹: دستور `find` چیست؟

**پاسخ:**

دستور `find` برای جست‌وجوی فایل‌ها و پوشه‌ها بر اساس معیارهایی مانند نام، نوع و زمان تغییر استفاده می‌شود.

جست‌وجوی فایل با نام مشخص در مسیر جاری:

```bash
find . -name "notes.txt"
```

جست‌وجوی تمام فایل‌های متنی:

```bash
find . -type f -name "*.txt"
```

جست‌وجوی پوشه‌ها:

```bash
find . -type d
```

در این مثال‌ها:

- `.` به معنی مسیر جاری است.
- `-type f` فایل‌های معمولی را انتخاب می‌کند.
- `-type d` پوشه‌ها را انتخاب می‌کند.
- `-name` نام موردنظر را مشخص می‌کند.

### سؤال ۲۰: دستور `grep` چه کاربردی دارد؟

**پاسخ:**

دستور `grep` برای جست‌وجوی متن یا الگو در محتوای فایل‌ها استفاده می‌شود.

مثال:

```bash
grep "error" application.log
```

این دستور خطوط حاوی عبارت `error` را نمایش می‌دهد.

گزینه‌های پرکاربرد:

```bash
grep -i "error" application.log
grep -n "error" application.log
grep -r "TODO" .
```

- `-i`: نادیده‌گرفتن تفاوت حروف بزرگ و کوچک
- `-n`: نمایش شماره خط
- `-r`: جست‌وجوی بازگشتی در فایل‌های یک پوشه

**تفاوت مهم:** `find` برای پیدا کردن فایل‌ها و پوشه‌هاست؛ `grep` برای جست‌وجوی متن در محتوای فایل‌هاست.

### سؤال ۲۱: دستور `which` چیست؟

**پاسخ:**

دستور `which` مسیر اجرایی دستوری را که از طریق محیط `PATH` پیدا می‌شود، نمایش می‌دهد.

مثال:

```bash
which ls
which python3
```

اگر برنامه از طریق `PATH` پیدا نشود، ممکن است خروجی‌ای نمایش داده نشود.

در برخی محیط‌ها، دستور `type` نیز برای تشخیص نوع یک نام دستوری مفید است:

```bash
type cd
type ls
```

این دستور می‌تواند مشخص کند نام موردنظر یک دستور داخلی Shell، یک فایل اجرایی یا نوع دیگری از تعریف دستوری است.

## ۸. دریافت راهنمای دستورات

### سؤال ۲۲: دستور `man` چیست؟

**پاسخ:**

دستور `man` برای مشاهده صفحات راهنمای رسمی بسیاری از دستورات و ابزارهای لینوکس استفاده می‌شود.

مثال:

```bash
man ls
man cp
man grep
```

در صفحه راهنما می‌توان ساختار دستور، گزینه‌ها، توضیحات و مثال‌ها را مطالعه کرد.

برای خروج از صفحه راهنما معمولاً کلید `q` را فشار می‌دهیم.

### سؤال ۲۳: دستور `--help` چه کاربردی دارد؟

**پاسخ:**

بسیاری از برنامه‌ها گزینه `--help` را برای نمایش خلاصه‌ای از نحوه استفاده و گزینه‌های مهم ارائه می‌کنند.

```bash
ls --help
cp --help
grep --help
```

این روش معمولاً سریع‌تر از مطالعه کامل صفحه راهنماست.

### سؤال ۲۴: دستور `apropos` چیست؟

**پاسخ:**

دستور `apropos` برای جست‌وجوی صفحات راهنما براساس یک واژه یا موضوع استفاده می‌شود.

```bash
apropos directory
apropos copy
```

اگر پایگاه داده صفحات راهنما در سیستم آماده نباشد یا به‌روز نباشد، ممکن است نتیجه مناسبی دریافت نکنید.

## ۹. آشنایی مقدماتی با ورودی و خروجی

### سؤال ۲۵: عملگر `>` چه کاربردی دارد؟

**پاسخ:**

عملگر `>` خروجی استاندارد یک دستور را در فایل می‌نویسد و اگر فایل از قبل وجود داشته باشد، محتوای قبلی آن را جایگزین می‌کند.

```bash
ls > files.txt
```

در این مثال، خروجی دستور `ls` داخل فایل `files.txt` نوشته می‌شود.

### سؤال ۲۶: عملگر `>>` چه تفاوتی با `>` دارد؟

**پاسخ:**

عملگر `>>` خروجی را به انتهای فایل اضافه می‌کند و محتوای قبلی را حفظ می‌کند.

```bash
echo "First line" > sample.txt
echo "Second line" >> sample.txt
cat sample.txt
```

خروجی:

```text
First line
Second line
```

### سؤال ۲۷: عملگر Pipe یا `|` چیست؟

**پاسخ:**

Pipe خروجی استاندارد یک دستور را به ورودی استاندارد دستور بعدی متصل می‌کند.

مثال:

```bash
ls -l | less
```

در این دستور، خروجی `ls -l` به `less` داده می‌شود تا بتوان آن را صفحه‌به‌صفحه مشاهده کرد.

مثال دیگر:

```bash
cat application.log | grep "error"
```

این دستور خطوط حاوی `error` را نمایش می‌دهد؛ هرچند برای این مثال، اجرای مستقیم `grep "error" application.log` ساده‌تر است.

## ۱۰. چند دستور پایه مفید دیگر

### سؤال ۲۸: دستور `whoami` چه کاربردی دارد؟

**پاسخ:**

نام کاربر مؤثر فعلی را نمایش می‌دهد.

```bash
whoami
```

### سؤال ۲۹: دستور `date` چیست؟

**پاسخ:**

تاریخ و زمان سیستم را نمایش می‌دهد.

```bash
date
```

### سؤال ۳۰: دستور `uname` چه کاربردی دارد؟

**پاسخ:**

اطلاعاتی درباره هسته سیستم‌عامل و معماری سیستم نمایش می‌دهد.

```bash
uname
uname -a
uname -r
```

- `uname`: نام هسته
- `uname -a`: مجموعه‌ای از اطلاعات سیستم
- `uname -r`: نسخه انتشار هسته

### سؤال ۳۱: دستور `clear` چیست؟

**پاسخ:**

صفحه ترمینال را پاک می‌کند.

```bash
clear
```

این دستور صرفاً صفحه نمایش ترمینال را پاک می‌کند و فایل‌ها یا تاریخچه دستورات را حذف نمی‌کند.

### سؤال ۳۲: دستور `history` چه کاربردی دارد؟

**پاسخ:**

دستور `history` فهرستی از دستورات ثبت‌شده در تاریخچه Shell را نمایش می‌دهد.

```bash
history
```

برای مشاهده تعداد محدودی از دستورات اخیر:

```bash
history 10
```

محتوای تاریخچه به تنظیمات Shell و نحوه اجرای نشست کاربر وابسته است.

## ۱۱. تمرین جامع آزمایشگاه

### سناریو

فرض کنید باید ساختار اولیه پوشه‌های یک پروژه دانشجویی را ایجاد کنید، چند فایل بسازید، محتوای آن‌ها را مشاهده کنید و یک عبارت را جست‌وجو کنید.

دستورات زیر را به‌ترتیب اجرا کنید:

```bash
mkdir -p ~/os2-lab/session3/project/docs
mkdir -p ~/os2-lab/session3/project/backup

cd ~/os2-lab/session3/project

touch docs/intro.txt
touch docs/commands.txt

echo "Linux is an operating system." > docs/intro.txt
echo "The grep command searches text." > docs/commands.txt

cat docs/intro.txt
cat docs/commands.txt

cp docs/intro.txt backup/
mv docs/commands.txt docs/linux-commands.txt

find . -type f
grep -n "Linux" docs/intro.txt
ls -lR .
```

### انتظار می‌رود دانشجو بتواند:

۱. ساختار پوشه‌ها را توضیح دهد.  
۲. تفاوت مسیر مطلق و نسبی را بیان کند.  
۳. کاربرد هر دستور را شرح دهد.  
۴. توضیح دهد کدام دستور فایل را کپی و کدام دستور آن را جابه‌جا کرده است.  
۵. خروجی دستور `find` را تفسیر کند.  
۶. توضیح دهد چرا `grep` در فایل `intro.txt` عبارت `Linux` را پیدا می‌کند.

## ۱۲. سؤالات پایان جلسه

### سؤالات تشریحی

۱. تفاوت ترمینال و Shell چیست؟

۲. کاربرد دستورات `pwd`، `ls` و `cd` را توضیح دهید.

۳. تفاوت مسیر مطلق و نسبی چیست؟ برای هرکدام مثال بزنید.

۴. تفاوت دستورات `cp` و `mv` چیست؟

۵. تفاوت `rm` و `rmdir` را توضیح دهید.

۶. دستورات `cat`، `less`، `head` و `tail` چه کاربردهایی دارند؟

۷. تفاوت `find` و `grep` چیست؟

۸. تفاوت عملگرهای `>` و `>>` را با مثال توضیح دهید.

۹. دستور `man` چه کاربردی دارد؟

۱۰. دستور `tail -f` در چه شرایطی مفید است؟

### تمرین‌های عملی

**تمرین ۱:** پوشه‌ای به نام `exam` در پوشه خانگی ایجاد کنید و داخل آن سه فایل متنی بسازید.

**تمرین ۲:** یکی از فایل‌ها را کپی کنید و نام نسخه کپی‌شده را تغییر دهید.

**تمرین ۳:** با استفاده از `find` تمام فایل‌های متنی موجود در ساختار تمرین را پیدا کنید.

**تمرین ۴:** در یکی از فایل‌ها عبارت `Linux` را جست‌وجو کنید و شماره خط آن را نمایش دهید.

**تمرین ۵:** خروجی دستور `ls -l` را در یک فایل ذخیره کنید و سپس یک خط دیگر به انتهای آن اضافه کنید.

**تمرین ۶:** صفحه راهنمای دستورات `grep` و `find` را باز کنید و سه گزینه کاربردی هرکدام را یادداشت کنید.
